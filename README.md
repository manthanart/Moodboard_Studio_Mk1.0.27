# Manthan Tandel — Moodboard Studio

A browser-based visual moodboard tool for organising reference images, arranging a Pinterest-style masonry canvas, editing colour swatches, and exporting moodboard layouts.

## Features

- Bulk image upload and visual reference collection
- Pinterest-style masonry moodboard canvas
- Adjustable column count
- Drag-and-drop card arrangement
- Image frame resizing and crop-to-fill behaviour
- Editable colour swatches with HEX values
- Dominant-colour suggestions and colour-based organisation
- PNG export and split-board export features where supported by the app

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser such as Google Chrome.
3. Upload images and start building your moodboard.

Some export features may rely on a third-party library loaded from a CDN, so an internet connection may be required.

## Deploy with GitHub Pages

1. Create a GitHub repository named `manthan-tandel-moodboard-studio`.
2. Upload `index.html` and this `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Notes

This is a client-side prototype. Unless a feature explicitly saves data, moodboard data may not persist after closing or refreshing the browser. Test the interactions and exports in your target browser before relying on them for production work.
